Getting Started
===============

Welcome to **TaskFlow Notes**. This guide covers installation and your first note.

Installation
____________

Install the CLI tool using ``pip``:

.. code-block:: bash

	pip install taskflow-notes

.. note::
	Make sure you are using Python 3.10 or newer.

Basic Commands
______________

* ``taskflow init`` - Initialize a local notes database.
* ``taskflow add "Buy coffee"`` - Create a new task note.
* ``taskflow list`` - Show open tasks.
